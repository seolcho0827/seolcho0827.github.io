我的世界存档渲染工具 — MCOverviewerGUI

一个为 Minecraft Overviewer 打造的 Windows 图形界面，让地图渲染不再需要敲命令行。

缘起

从 2018 年开始接触 Minecraft，断断续续玩了 8 年，期间也做过一段时间服主。一直有个痛点：没办法快速渲染服务器存档地图。

服务端虽然有地图插件，但查看不方便；客户端又只能看到自己探索过的区域。最关键的是——作为服主，没法把服务器地图同步给群友。

于是这个扣子一直埋在心里，直到我发现了 Minecraft-Overviewer 这个项目。

项目简介

Overviewer 是一个强大的 Minecraft 地图渲染工具，但原作者早已弃坑，且只支持命令行操作，对不熟悉终端的用户非常不友好。

我把它捡了起来，用 Python + PyQt5 给它套了一层图形界面，做出了 MCOverviewerGUI——一个开箱即用的 Windows 桌面应用。

项目地址：MCOverviewerGUI

功能特性

  • 地图渲染 — 将 Minecraft 世界存档渲染为可浏览的网页地图
  • 多种渲染模式 — 支持 Normal、Cave、Nether 等模式，可多选
  • 实时进度显示 — 渲染过程中展示进度和详细日志
  • 一键打包 — 渲染完成后自动生成 tar.gz 压缩包，方便分享
  • 灵活配置 — 自定义进程数、输出目录、地图标题等参数
  • 存档信息查看 — 选择世界存档后可查看基本信息
  • 中文路径支持 — 无需担心路径中包含中文字符

快速开始

环境要求

  • Windows 操作系统
  • Python 3.8 或更高版本

如果还没装 Python，前往 Python 官网 下载安装，安装时记得勾选 “Add Python to PATH”。

运行方式

最简单的方式——双击项目根目录下的 run.bat 即可。脚本会自动完成以下操作：

  1. 检测系统中已安装的 Python
  2. 自动安装缺失的依赖（PyQt5、requests）
  3. 启动图形界面

当然，也可以手动运行：

pip install -r requirements.txt
python main.py

使用流程

  1. 选择 Minecraft 世界存档目录
  2. 选择渲染输出目录
  3. 选择渲染模式（支持多选）
  4. 设置进程数（建议填逻辑核心数）
  5. 可选：设置自定义地图标题
  6. 点击 “开始渲染”
  7. 实时查看渲染进度和日志
  8. 渲染完成后可选择是否打包为 tar.gz

常见问题

问题 解决方案
纹理缺失错误 程序会自动查找 Minecraft 安装位置获取纹理，也可手动将纹理文件放入 resource_pack 目录
中文路径问题 已支持中文路径，但仍需注意文件夹权限
权限被拒绝 尝试以管理员身份运行，或检查文件夹权限
Python 未找到 确保已正确安装 Python 并添加到系统 PATH

项目结构

MCOverviewerGUI/
├── core/                     # 核心功能模块
│   ├── config_manager.py      # 配置管理
│   └── renderer.py            # 渲染引擎
├── gui/                      # GUI 界面模块
│   ├── download_dialog.py     # 下载对话框
│   └── main_window.py         # 主窗口
├── utils/                    # 工具模块
│   ├── logger.py              # 日志系统
│   └── minecraft_downloader.py # Minecraft 下载器
├── resource_pack/             # 资源包和纹理
├── main.py                    # 程序入口
├── requirements.txt           # Python 依赖
├── run.bat                    # Windows 启动脚本（推荐）
├── run.ps1                    # PowerShell 启动脚本
└── config.example.json        # 配置示例

我的世界存档渲染工具

2026-06-12 1 分钟阅读 # Minecraft # Overviewer # Python # 存档 # 渲染

缘起

从2018年开始接触Minecraft以来，断断续续的玩了8年，期间也断断续续做了一段时间的服主，一直存在一个问题，没办法快速的渲染服务器的存档地图。虽然说服务器端和客户端都有地图然间，但服务端的不方便查看，客户端只能看到自己探明的地方，最主要的是做服主的没办法同步服务器地图给基友群友，于是这里就记下了一个扣子。

项目实现

自己在github上查看到一个项目Overviewer,这个项目原作者已经弃坑很久，我将它捡起来了。这个项目主要问题是命令行操作，我给它套了个皮，主要使用Python写的，剪断截说，项目大致是能跑起来了，可以解决Windows系统下存档渲染的功能。
